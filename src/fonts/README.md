# Fonts

Place the following files here:

- `Neus-Black.woff2`  — used for hero headlines (font-weight: 900)
- `Neus-Light.woff2`  — used for large accent text (font-weight: 300)

If you only have .ttf files, rename them to .woff2 OR update the `src` paths
in `src/app/layout.tsx` to use `.ttf` instead.

Obtain Neus from: https://www.onlinewebfonts.com/download/7b42867375ad94d39bf3b48d1bbd7fdb
(contains Regular only — for Black/Light you need the full Gatype package)
